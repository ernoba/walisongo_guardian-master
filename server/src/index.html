Walisongo Guardian
Platform monitoring komputer santri sebagai bentuk pengawasan yang sah dan terukur - Di kembangkan untuk tujuan menjaga batasan para santri dalam mengakses internet. - Di bangun dengan Rust dan di jalankan dengan Melisa Arch. - "Cemangat Bang Nalo"

Kemampuan Utama
  • Tangkapan layar real-time dengan pemuat progresif
  • Pencatatan input keyboard dengan konteks penuh
  • Pelacakan aplikasi dan browser yang sedang aktif
  • Penghubungan cerdas tangkapan dan ketikan
  • Analisis visual konten via Claude Vision API
  • Statistik interaktif dan peta panas aktivitas
  • Pencarian paralel di seluruh log aktivitas

Kebijakan Penggunaan

Persetujuan — Semua pengguna memahami dan menyetujui pemantauan sistem. Orang tua dan siswa telah menerima penjelasan.

Larangan — Dilarang mengakses konten berbahaya, bermain game di luar jadwal, dan aktivitas siber merugikan.

Privasi — Log aktivitas bersifat rahasia, hanya diakses staf berwenang. Data dikelola sesuai standar privasi institusi.
